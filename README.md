# vitaeflow.org

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Source code for [vitaeflow.org](https://vitaeflow.org) — the website for the VitaeFlow open standard.

Built with [Astro](https://astro.build).

## Development

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # Production build → ./dist/
```

## Ecosystem

| Project | Description |
|---------|-------------|
| [VitaeFlow Spec](https://github.com/VitaeFlow/vitaeflow-spec) | JSON schema and PDF embedding standard |
| [@vitaeflow/sdk](https://github.com/VitaeFlow/vitaeflow-js) | JavaScript/TypeScript SDK |
| [vitaeflow CLI](https://github.com/VitaeFlow/vitaeflow-cli) | Command-line tool |
